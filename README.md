## 🚀 Quick Start (5 minutes)

### Option 1: Deploy Directly from GitHub

1. **Fork/Clone this repository**
   ```bash
   git clone https://github.com/YOUR-USERNAME/farhana-portfolio.git
   cd farhana-portfolio
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Run locally to test**
   ```bash
   npm run dev
   ```
   Open [http://localhost:3000](http://localhost:3000) in your browser

4. **Push to GitHub**
   ```bash
   git add .
   git commit -m "Initial commit"
   git push origin main
   ```

5. **Deploy to Vercel**
   - Go to [vercel.com](https://vercel.com)
   - Import your GitHub repository
   - Click "Deploy"
   - ✅ Done! Your site is live!

### Option 2: Deploy via Vercel Dashboard (Even Easier)

1. **Visit [vercel.com/new](https://vercel.com/new)**
2. **Connect your GitHub account**
3. **Select this repository**
4. **Click "Deploy"** and wait 1-2 minutes
5. **Get your live URL!** 🎉

## 🌐 Custom Domain

Want to use a custom domain like `farhana-shakeer.com`?

1. **Register a domain** at GoDaddy, Namecheap, or Google Domains
2. **In Vercel**: Settings → Domains → Add your domain
3. **Add DNS records** provided by Vercel in your domain registrar
4. **Wait 24-48 hours** for DNS propagation
5. **Done!** Your site is live on your custom domain

## 🐛 Troubleshooting

### Build fails locally
```bash
# Clear cache and reinstall
rm -rf node_modules package-lock.json
npm install
npm run dev
```

### Vercel deployment fails
- Check that all files are pushed to GitHub
- Verify `package.json` exists
- Check Vercel logs in the deployment tab

### Port already in use
```bash
# Stop the current process and restart
npm run dev
```
